🌸 Digital Pookalam

«Where Tradition Blossoms Through Code»

Digital Pookalam is a creative web-based recreation of Kerala's traditional Pookalam, created for Code A Pookkalam, organized by TinkerHub NSSCE.

The project combines Kerala's cultural heritage with modern web technologies, using HTML, CSS, and JavaScript to transform lines of code into vibrant floral patterns and a digital Pookalam.

✨ Features

- 🌼 Digital recreation of a traditional Pookalam
- 🎨 Intricate floral patterns and vibrant colors
- 💻 Built using HTML, CSS, and JavaScript
- ✨ Animations and visual effects
- 📱 Responsive design

🛠️ Technologies Used

- HTML5 — Structure and layout
- CSS3 — Styling, patterns, animations, and visual effects
- JavaScript — Interactivity and dynamic elements

🤖 AI Assistance

Generative AI was used as an assisting tool during development for ideation, coding assistance, refinement, and debugging.

🌺 About Code A Pookkalam

Code A Pookkalam is an event organized by TinkerHub NSSCE, bringing together creativity, culture, and technology by challenging participants to create Pookkalams through code.

Digital Pookalam is my take on the challenge, reimagining a traditional Onam art form through modern web technologies.

🎯 Concept

Tradition Meets Technology

Instead of arranging physical flowers, Digital Pookalam uses code to create patterns, colors, symmetry, and visual elements inspired by the traditional Pookalam.

The project explores how programming can become a medium for artistic expression while celebrating Kerala's cultural heritage.
